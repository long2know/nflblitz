Contact272/M1/impact and original normal-camera prerequisites. This is real
original-C comparison plus compiled production C# controls, not the asset-free
portable player selector or an optional local-authority campaign.

installation, browser, server, Unity Editor or generated-source upload.

## Mandatory coverage and failure gates

`run.py` requires **both** `--authority` and `--controls`. It always compiles and
executes the selected original C, requires exactly40 scenarios/4,760 declared
dispatches and compares every scenario with the actual C# outputs. It requires
50 managed cases/2,240 assertions, all21 distinct zero-diagnostic compiled
production mutants with their named failure, and an identical final baseline.
It cannot report success for managed-only or controls-omitted execution.

The original47 cases/1,199 assertions and all17 original controls are retained.
Both original real-Core integration cases now bind the production
`SourceCabinetPlaySelection.ApplyAtSourceTick`; the rejected version called it
at1,2,104 and failed on104, despite the formerly unbound suite passing.
`CabinetLifecycle.cs` adds three persistent cases with1,041 further assertions:
the actual cabinet buffer, fixed-step bridge, selector, Core, camera and authored
HUD together with FX disabled/enabled, plus strict source ordering and menu
process admission. They exercise all four non-index-ordered configured stations,
press/hold/release observations during suspension, no frozen actor/history/game/
clock/RNG work, message/child cleanup, same-wake later actors, next-wake earlier
game/clock/status/FX, public captain selection/flip/new play, focus/neutral and
full restart. A separately suspended real menu consumer preserves its sleep20.
Duplicate/reordered/unexplained-gap/current-snapshot failures and configured
station completeness remain explicit.

Four additional zero-diagnostic compiled mutations remove suspended-tick input
observation, weaken the consecutive-tick guard, execute the suspended menu or
skip its sleep20. Each must fail its own named assertion. The17 inherited
mutation names and failure requirements remain mandatory. Original-C output
comparison also runs when all40 trace artifacts were emitted before a later
managed assertion failed; the managed failure is retained, never suppressed.
This preserves the original flasher/order mutation checks while allowing the
real HUD to reject an invalid message earlier.
